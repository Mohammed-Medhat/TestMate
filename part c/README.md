# TestMate APR

Automated Program Repair system using SBFL fault localisation + a QLoRA fine-tuned Qwen model + AST-safe patching.

---

## Project Structure

```
testmate/
│
├── config.py                  ← All paths & hyperparameters (single source of truth)
├── buggy_code.py              ← The file being repaired (modified in-place by the pipeline)
├── test_logic.py              ← Pytest test suite for the buggy file
├── requirements.txt
│
├── core/                      ← APR engine
│   ├── __init__.py
│   ├── inference.py           ← Loads base Qwen model + LoRA adapter
│   ├── model_runner.py        ← Thread-safe singleton wrapper around the LLM
│   ├── run_and_collect.py     ← Per-test coverage runner (builds SBFL spectrum)
│   ├── sbfl_localiser.py      ← Ochiai scoring & line ranking
│   └── control_loop.py        ← CLI repair loop (SBFL → prompt → patch → verify)
│
├── training/                  ← Dataset & fine-tuning
│   ├── __init__.py
│   ├── dataset_factory.py     ← Builds train/test JSONL from QuixBugs + synthetic patterns
│   └── train.py               ← QLoRA fine-tuning script
│
├── web/                       ← Flask web UI
│   ├── app.py                 ← Flask server with SSE streaming pipeline
│   └── templates/
│       └── index.html         ← Frontend (live logs, SBFL viewer, code diff)
│
├── models/
│   ├── Qwen_Model/            ← Base model weights (download separately)
│   ├── adapter/               ← LoRA adapter output (generated by train.py)
│   └── cache/                 ← HuggingFace download cache
│
├── data/
│   ├── train_prepared.jsonl   ← Generated by dataset_factory.py
│   └── test_prepared.jsonl
│
└── artifacts/                 ← Model patch outputs per attempt (auto-generated)
```

## Quickstart

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Download the base model

Place the Qwen model weights inside `models/Qwen_Model/`.
The folder must contain `config.json`, `tokenizer.json`, and the model weight shards.

### 3. Build the training dataset

```bash
python -m training.dataset_factory
```

This generates `data/train_prepared.jsonl` and `data/test_prepared.jsonl`.

### 4. Train the LoRA adapter

```bash
python training/train.py
```

The adapter is saved to `models/adapter/` and must contain:
- `adapter_config.json`
- `adapter_model.safetensors`

> If you already have a pre-trained adapter, copy those two files into `models/adapter/` and skip this step.

### 5a. Run via Web UI (recommended)

```bash
python web/app.py
```

Open `http://localhost:5000` in your browser.
Click **Run Pipeline** to start the APR loop with live logs.

### 5b. Run via CLI

```bash
python core/control_loop.py
```

## How the Pipeline Works

```
buggy_code.py  +  test_logic.py
        │
        ▼  Step 1
    pytest  →  tests fail?
        │
        ▼  Step 2
    run_and_collect.py
    (coverage run per test)
        │
        ▼
    sbfl_localiser.py
    (Ochiai score per line)
        │
        ▼  Step 3
    Build repair prompt
    (trace + suspicious snippet + full code)
        │
        ▼  Step 4
    model_runner.py → Qwen + LoRA
        │
        ▼  Step 5
    AST patch (replace only matching functions)
        │
        ▼  Step 6
    Re-run pytest → fixed? → done
                           → retry (max 3 attempts)
```

## Common Errors

### `Can't find 'adapter_config.json'`

Your adapter files are missing or in the wrong folder.
Expected location: `models/adapter/adapter_config.json`

**If you trained the model:** make sure `train.py` completed successfully.
It saves directly to `models/adapter/`.

**If you have an existing adapter somewhere else** (e.g. the old `Final/` folder):
```bash
cp /path/to/your/old/Final/adapter_config.json   models/adapter/
cp /path/to/your/old/Final/adapter_model.bin      models/adapter/
```

### `Patch rejected: NO function found`

The model returned text that didn't contain a Python function definition.
This usually means the model output was empty or was just an explanation in plain English.
The pipeline retries automatically up to 3 times.

### SBFL scores all zero

This was a bug in the original `run_and_collect.py` — all files' line numbers were
merged together, zeroing out the failed counts. Fixed in this version.
Make sure you are using `core/run_and_collect.py` from this structure.

## Configuration

All paths and hyperparameters live in `config.py`:

| Variable | Default | Description |
|---|---|---|
| `MODEL_NAME` | `models/Qwen_Model` | Base model path |
| `ADAPTER_PATH` | `models/adapter` | LoRA adapter path |
| `OUTPUT_DIR` | `models/adapter` | Where train.py saves the adapter |
| `MAX_LENGTH` | 2048 | Max token length |
| `BATCH_SIZE` | 1 | Training batch size |
| `LEARNING_RATE` | 2e-4 | Training learning rate |
| `NUM_EPOCHS` | 3 | Training epochs |
